## 系统做什么

输入一份文本、代码、推理或技术方案，依次经过 Analyst 初审、Critic 质疑、Judge 汇总。每个角色使用独立系统提示词。Critic 收到原文与初审，Judge 收到原文和前面两份有效回答。

程序负责组织材料、执行顺序和错误处理；模型生成评审内容。固定回答的 fake 示例只证明流程，无法证明审核质量。

<summary>文件职责与完整调用链</summary>

```text
页面 → 本地 HTTP → FastAPI → ReviewService
    → 异步工作流 → Analyst → Critic → Judge → 报告校验
    → API 响应 → 页面核验、保存与展示
```

| 位置 | 负责什么 |
| --- | --- |
| app.py | 输入、提交与展示 |
| api_client.py | 页面访问本地 API，核验响应 |
| api.py / api_models.py | HTTP 路由、请求与公开响应 |
| service.py | 容量、活动标识、任务生命周期 |
| workflow.py | 角色顺序、上下文、阶段状态、期限 |
| agents.py | 三个角色的名称与系统提示词 |
| contracts.py | 输入与最终报告的业务规则 |
| clients.py | 模型请求、响应与网络错误 |
| config.py / environment.py | 配置读取与环境加载 |

除 app.py 外，上表模块均在 review_system/。按函数名定位，不依赖会漂移的行号。同步入口 run_review 是适配层，主业务内核仍是异步的 run_review_async。

<details>
<summary>阶段 9–10：数据契约与部分结果</summary>

原文必须是非空白字符串，最多 20,000 个 Python 字符，保留原样。review_mode 允许 logic 或 evidence；两种模式都只评估提供的材料，不代表联网核验。

Judge 的报告包含 summary、verdict、findings、limitations。程序继续检查字段、枚举、引用范围、摘录与原文切片以及跨字段关系。JSON 能解析不等于报告合法，格式合法也不等于结论正确。

Analyst 与 Critic 的有效回答在后续失败时保留。Critic 模型失败则不启动 Judge；Judge 报告非法则保留前两份回答，非法原始输出单独记录，最终报告为空。可选回调发生在保存当前有效回答之后，所以回调失败时保留数量可能不同。

result.final_response 是 Judge 原始 JSON 文本，result.record.final_review 是通过校验的报告对象。完整细节和实验在仓库数据契约专题。

</details>

<details>
<summary>阶段 11–12：等待、期限与取消</summary>

同一审核必须按 A → C → J 执行；不同审核可在等待网络时交替推进。共享传输客户端不表示共享当前审核的上下文。

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| REVIEW_TIMEOUT_SECONDS | 60 秒 | HTTPX 网络操作超时 |
| REVIEW_MODEL_TIMEOUT_SECONDS | 60 秒 | 一次模型调用预算 |
| REVIEW_TOTAL_TIMEOUT_SECONDS | 150 秒 | 整次审核总预算 |

总期限不在每个角色开始时重置。取消后需要等待任务清理，释放本次取得的资源；某一审核失败不能关闭仍被其他审核借用的共享客户端。本地取消不证明供应商停止处理或计费。

</details>

<details>
<summary>阶段 13–14：接口与页面</summary>

GET /healthz 是轻量健康检查，不调用模型。POST /api/v1/reviews 等本次审核完成后返回，页面收到完整响应后展示全部有效阶段，没有逐阶段推送。

| 状态码 | 含义 |
| --- | --- |
| 201 | 执行成功且报告合法，结论仍可为需要修改或证据不足 |
| 422 | 请求无效 |
| 409 | 同一 request_id 仍在执行 |
| 429 | 本地同时审核容量已满 |
| 502 | 模型调用或输出失败 |
| 504 | 网络、模型或整次审核预算超时 |

服务使用单 worker，最多同时接受两份审核。活动标识仅在执行期间去重，完成后再次提交会再次调用模型。没有持久化幂等、历史查询或自动重试。

页面普通重跑可恢复当前会话已收到的结果；新提交先清理旧结果。页面渲染失败与内核回调失败属于不同边界。

</details>

<summary>运行演示：需要时再用</summary>

终端持续运行是在等待请求。需要结束时在各自终端按 Ctrl+C。真实模型的供应商、地址、模型和凭据通过后端环境配置，凭据仅留在本机，不写进学习记录。
